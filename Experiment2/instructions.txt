Experiment 2: Install, configure and run Hadoop and HDFS

Installation Process:
Prerequisites: Ensure you have a minimum of 8GB RAM, a Quad-core CPU, JRE 1.8, JDK 1.8, and 7Zip or WinRar.
Download & Extract: Download the hadoop-2.9.2.tar.gz file and extract it using 7Zip. Create a folder without spaces (e.g., D:\hadoop-2.9.2) and place the extracted files there.

Environment Variables:
Create a New User Variable JAVA_HOME pointing to your JDK path (e.g., C:\Program Files\Java\jdk1.8.0_221).
Create a New User Variable HADOOP_HOME pointing to your Hadoop path.
Edit the Path System Variable and add %JAVA_HOME%\bin, %HADOOP_HOME%\bin, and %HADOOP_HOME%\sbin.

Create Directories: Inside the Hadoop directory, create a data folder. Inside data, create two subfolders: namenode and datanode.

Configuration Files: Edit the following files in etc/hadoop:

core-site.xml:
<configuration>
<property><name>fs.defaultFS</name><value>hdfs://localhost:9000</value></property>
</configuration>

hdfs-site.xml:
<configuration>
<property><name>dfs.replication</name><value>1</value></property>
<property><name>dfs.namenode.name.dir</name><value>C:\hadoop\data\namenode</value></property>
<property><name>dfs.datanode.data.dir</name><value>C:\hadoop\data\datanode</value></property>
</configuration>

mapred-site.xml:
<configuration>
<property><name>mapreduce.framework.name</name><value>yarn</value></property>
</configuration>

yarn-site.xml:
<configuration>
<property><name>yarn.nodemanager.aux-services</name><value>mapreduce_shuffle</value></property>
<property><name>yarn.nodemanager.auxservices.mapreduce.shuffle.class</name><value>org.apache.hadoop.mapred.ShuffleHandler</value></property>
</configuration>

hadoop-env.cmd: Set set JAVA_HOME="C:\Program Files\Java\jdk1.8.0_221".

Format & Run:
Open a command prompt and run hadoop namenode -format.
Run start-all.cmd as administrator to launch the Hadoop daemons.
